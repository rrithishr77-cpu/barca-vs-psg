# Barcelona vs PSG Match Prediction ⚽

I won! My model predicted PSG as the more likely winner against Barcelona, and PSG actually won!

## 📌 Project Overview

This project uses football statistics and machine learning to analyze team performance and predict match outcomes.

## 📊 Analysis

- Current team form
- Attacking quality
- Home vs away performance
- Historical Barcelona vs PSG encounters
- Match outcome prediction

## 🤖 Machine Learning Models

- Logistic Regression
- Random Forest
- Gradient Boosting

## 📂 Datasets

- La Liga — current and previous seasons
- Ligue 1 — current and previous seasons
- Historical UEFA Champions League encounters between Barcelona and PSG

## 💡 Key Takeaway

The model predicted PSG as the more likely winner, and PSG won! However, one correct prediction does not prove model reliability. Further testing on unseen matches is needed.
